# London Road Safety Priorities

## About the Project
This project uses Microsoft Power BI to explore road collision data in London. The aim is to organise the data and present it through interactive dashboards.

## Project Objectives
- Explore road collision data.
- Analyse collision severity and casualties.
- Compare collision data across London boroughs.
- Examine road layouts and collision times.
- Present the data using interactive visualisations.

## Tools and Technologies
- Microsoft Power BI
- CSV dataset

## Dashboard Pages
The Power BI report contains four pages:

1. **London Road Safety** – Overview of the project data.
2. **Severity and Casualties** – Information about collision severity and casualties.
3. **Borough and Road Layout** – Exploration of boroughs and road layouts.
4. **Time Analysis** – Exploration of collision data over time.

## Project Files
- Power BI report 

## How to View the Project
Download the Power BI report file and open it using Microsoft Power BI Desktop to explore the dashboard pages and interact with the visualisations.

## Project Status
This project was created as part of a data analytics portfolio to practise data visualisation and dashboard development using Power BI.
